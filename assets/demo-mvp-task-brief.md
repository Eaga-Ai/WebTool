# Shopify SEO App Opportunity Demo

> Demo sample only. This is not a complete market study or a revenue claim.
> 此為 demo 樣例，不代表完整市場研究或收入承諾。

## Opportunity Card

**Direction:** A lightweight Shopify SEO helper for merchants who need clearer product-page checks and editing guidance.

## Target User

Independent Shopify merchants who manage a small catalogue without a dedicated SEO specialist.

## Source Signals

- Merchants often need to switch between product copy, keyword notes, and store settings.
- Existing tools can feel too broad for one product-page workflow.

## Pain Points

- It is unclear which product-page issue to fix first.
- Editing suggestions still need manual review.
- Subscription cost is difficult to justify before results are visible.

## MVP Scope

- Paste one Shopify product description.
- Return a short, editable SEO checklist.
- Save one improvement task for later review.

## What Not to Build

- A complete SEO platform.
- Automated publishing or bulk store changes.
- Complex team roles or membership controls.

## 7-day Validation Checklist

1. Talk to 3–5 Shopify merchants.
2. Ask how they review and improve one product page today.
3. Confirm which task is repeated and costly.
4. Test a manual checklist with 1–2 merchants.
5. Decide whether a minimal prototype is worth building.

## Codex / Trae Task Brief

Build a minimal web prototype that accepts one product description and returns an editable SEO improvement checklist. Focus on validating the workflow. Do not build a full Shopify app, payment flow, membership system, or automated publishing.
